# Portfolio personnel

## Prévisualiser
Ouvre `index.html` dans ton navigateur.

## Personnaliser avant publication
- Ajoute ton prénom et ton lycée si tu souhaites les afficher.
- Remplace `TON.ADRESSE@EXEMPLE.FR` par une adresse dédiée.
- Ajoute ton vrai lien GitHub.
- Vérifie chaque description de projet et retire ce que tu n'as pas réalisé.
- Ajoute des captures d'écran personnelles dans les fiches projets.

## Publier gratuitement avec GitHub Pages
1. Crée un dépôt GitHub nommé `tonpseudo.github.io`.
2. Ajoute `index.html` à la racine du dépôt.
3. Dans Settings > Pages, sélectionne le déploiement depuis la branche principale.
4. Ton site sera accessible à l'adresse `https://tonpseudo.github.io`.

Le site est autonome : aucun framework ni dépendance externe n'est nécessaire.
